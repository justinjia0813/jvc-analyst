# 星尘工坊 Comps/DD（Comparable Companies Analysis / Due Diligence，可比公司分析/尽职调查，用于核验竞争与可比对象）示例

> 本文全部公司、数值和来源位置均为虚构演示，只用于展示结构，不得用于真实投资判断。

## 范围与口径

| 项目 | 口径 |
| --- | --- |
| 目标项目/赛道 | 星尘工坊；面向中小制造企业的工业视觉质检方案 |
| 研究日期与地区 | 2026-06-11；中国为主、海外标杆为辅 |
| 产品与客户边界 | 比较质检模型训练、边缘部署及视觉设备；不比较通用机器学习平台 |
| 收入口径 | 最近完整年度公司收入；集团公司优先取视觉业务分部收入 |
| 估值/市值口径 | 初创公司融资估值与上市公司市值分列，均标日期，不直接混算 |
| 反向检索范围 | 客户采购、续费、撤单、产品停产、监管处罚及分部收入披露 |
| 不覆盖事项 | 团队、法务、财务真实性等项目全套尽调；不输出投资结论 |
