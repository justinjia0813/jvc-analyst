# 尽调报告关注清单

清单用来防止漏看，不要求逐项输出。只把实际发现写进摘要。

## 财务尽调 / 审计报告

- **收入确认**：确认时点（发货、验收、回款）、是否提前确认、跨期；合同额、收入、回款三者的差距。
- **客户与集中度**：前五大客户占比、关联客户、客户与供应商重叠、新增大客户的真实性。
- **应收与回款**：账龄结构、逾期比例、坏账计提是否充分、期后回款。
- **毛利真实性**：成本归集口径、研发费用资本化、人工和外包是否计入成本。
- **现金流**：经营现金流与净利润的差距、期末现金是否受限、票据。
- **关联交易与资金占用**：与股东、创始人、关联方的往来和借款。
- **或有负债**：担保、未决诉讼的财务影响、对赌或回购义务。
- **税务**：税务合规、欠缴、优惠资格的持续性。
- **调整事项**：尽调机构对管理层报表做的调整，调整前后净利润差多少。
- **内控**：资金审批、个人卡收支、账实不符。

## 法律尽调

- **股权沿革**：历次增资转让的价格和程序、代持及清理进度、出资是否实缴、股权质押冻结。
- **实际控制与治理**：一致行动、投票权安排、历史轮次的特殊权利（回购、优先清算、一票否决）及其冲突。
- **知识产权**：核心专利和软件著作权的权属人、职务发明、高校或原单位的权属主张、许可和转让协议。
- **高校与国资背景**：在岗创业的审批和报备、科技成果转化协议、国有股权程序。
- **重大合同**：主要客户和供应商合同的关键条款（排他、违约、控制权变更条款）。
- **诉讼与仲裁**：进行中和潜在的案件、标的额、可能结果、对核心资产或团队的影响。
- **资质与合规**：经营所需许可、环保安全、数据合规、出口管制。
- **劳动人事**：核心人员劳动关系、竞业限制、期权授予是否合规、社保公积金。

## 业务 / 技术尽调

- 技术成熟度（实验室、样机、试点、量产）的判断依据。
- 客户访谈结论与公司说法的差异。
- 产能、良率、交付周期的实测数据。
- 竞品对比的口径和测试条件。

## 条款处理的常用选项

| 发现类型 | 常见处理 |
| --- | --- |
| 已知且可量化的损失（欠税、罚款） | 估值调整或特别赔偿 |
| 需要在交割前解决（代持未清理、权属未转移） | 交割先决条件 |
| 无法完全核实的经营事实 | 陈述与保证，配合赔偿条款 |
| 交割后可以整改（内控、社保） | 交割后承诺事项及期限 |
| 影响核心资产或持续经营 | 暂停，回到投决讨论 |
