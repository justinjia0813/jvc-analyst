# 交叉比对方法

## 立场偏差速查

| 受访者类型 | 常见偏差 | 怎么校正 |
| --- | --- | --- |
| 目标公司客户 | 被推荐来的往往是满意客户；采购人和使用人看法不同 | 问具体采购、续约、替换经历；区分采购与使用角色 |
| 竞品或竞品前员工 | 倾向低估对手、高估自家路线 | 问可观察的事实（谁赢了哪个单、价格多少），少问评价 |
| 供应商 | 想卖更多，倾向乐观描述下游需求 | 问订单量、账期、实际提货节奏 |
| 目标公司前员工 | 离职原因影响态度；信息可能过时 | 问离职时间，只采信那时之前亲历的事 |
| 独立专家 / 学者 | 熟悉原理，可能不熟悉量产和价格 | 原理问题多采信，商业问题找产业侧印证 |
| 投资人 | 已投者倾向乐观，竞对的投资人倾向悲观 | 只采信有具体依据的说法 |

## 共识的强弱

- **强共识**：两位以上、立场不同（例如一位客户、一位竞品）、各自独立说出、有具体例子。
- **弱共识**：多人说法相同但立场相同，或都是转述，或都没有具体例子。
- **伪共识**：访谈人在问题里已经给出答案，受访者只是同意。原话里出现这种情况要标出。

## 分歧的处理顺序

1. 先对口径：时间、地区、产品范围、单位、是否含税、是否包含某类客户。
2. 再看信息位置：谁亲历、谁转述、谁的信息更新。
3. 再看利益关系：谁说成这样对自己有利。
4. 最后才判断谁更可信；判断不了就写需要什么证据。

## 下一轮问题怎么写

- 一个问题只为分辨一个分歧。
- 优先找能同时看到双方说法的人（例如同时采购过两家产品的客户）。
- 问发生过的具体事，不问观点。
