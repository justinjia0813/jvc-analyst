# 访谈题库与写法

题库是起点，不是清单。每次只挑和本次假设相关的问题，改写成贴合项目的原话。

## 通用写法

- **问发生过的事**：“最近一次……是怎么发生的”，好过“你们通常……”。
- **要具体一次**：“举一个最近的客户例子”，然后追问名字（可匿名）、时间、金额、谁拍板。
- **要分母**：“20 家客户里有几家付了第二笔钱”，好过“客户复购率怎么样”。
- **中性措辞**：不暗示期望答案。
- **留追问**：每个关键问题准备一个“如果对方说 X，就追问 Y”。

## 创始人 / 管理层

| 要验证 | 问法 | 警惕信号 |
| --- | --- | --- |
| 单位经济 | “拿最近签的那单拆一下：合同额多少，设备/人工/外包各花了多少，什么时候回款？” | 只给毛利率，不给成本构成；或拿预测代替已发生的单子 |
| 订单真实性 | “已签合同里，预付款到账了几笔？最大的一单现在走到哪一步？” | 把中标、框架协议、意向说成订单 |
| 收入口径 | “今年确认的收入里，哪些是验收后确认的，哪些是预收？” | 合同额、收入、回款混着说 |
| 现金与融资 | “账上现金现在多少，每月净花多少？不融资能撑到哪个月？” | 说不出月度消耗 |
| 创始人能力 | “公司遇到过最接近失败的一次是什么？当时你具体做了哪三件事？” | 只讲结果不讲自己的动作；把团队成绩全归到自己 |
| 判断力 | “过去一年你改变过的最大一个判断是什么？是什么让你改的？” | 从没改过判断，或改的原因都是外部 |
| 团队 | “最近离职的核心成员是谁，为什么走？” | 回避，或全部归因于对方 |
| 历史问题 | “这件事如果从对方角度讲，会怎么讲？” | 只有单方面叙述 |

## 客户

| 要验证 | 问法 | 警惕信号 |
| --- | --- | --- |
| 真实痛点 | “没用这家之前，这件事你们是怎么做的？一年花多少？” | 说不清原来的做法和成本 |
| 采购过程 | “最近一次采购是怎么发起的，谁批的预算，比较过哪几家？” | 没有比选；或决策人不是受访者 |
| 实际使用 | “现在每周/每月实际用几次？谁在用？” | 买了但没人用；只在演示时用 |
| 付款与复购 | “第一笔钱什么时候付的？后来又买过吗，为什么？” | 只有一次试点；续约还没到期却被说成复购 |
| 替代选择 | “如果明天这家公司没了，你们会怎么办？” | 很容易换，或回到原来的做法没损失 |

## 专家 / 行业人士

| 要验证 | 问法 | 警惕信号 |
| --- | --- | --- |
| 行业机制 | “这个环节里谁掌握定价权？成本压力最后落在谁身上？” | 只讲趋势，不讲钱怎么流 |
| 技术路线 | “这几条路线里，哪条最先卡在量产上？卡在哪？” | 只讲实验室指标 |
| 竞争 | “如果你是大厂，会自己做还是买？为什么？” | 忽略自建和维持现状 |
| 对项目方说法的核对 | “有公司说能做到 X，你觉得在什么条件下成立？” | 直接念公司名字导致对方客套；先问条件再问公司 |

## 前同事 / 推荐人

先问关系：一起工作多久、什么角色、是否有利益关系。再问具体情境：“你亲眼见过他处理的最难的一件事是什么？”朋友式推荐只作线索，同一个故事被多人重复不算多份证据。

## 尽调材料清单（会前或会后请对方提供）

按假设挑选：已签合同（可脱敏）、预付款/回款凭证、近 12 个月管理报表、成本拆分、客户名单与联系方式、股权结构与期权、历史融资协议、诉讼材料。
