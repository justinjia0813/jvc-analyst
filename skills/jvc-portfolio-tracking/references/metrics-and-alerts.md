# 指标口径与预警规则

## 取数口径

| 指标 | 取自 | 口径说明 |
| --- | --- | --- |
| 营业收入 | 利润表“营业总收入”或“营业收入” | 季报给本期金额和本年累计；月报给本月和本年累计。单季 = 本期累计 − 上期累计 |
| 毛利率 | (营业收入 − 营业成本) ÷ 营业收入 | 单季和累计分开算 |
| 净利润 | 利润表“净利润” | 注明是否含少数股东损益 |
| 经营现金流 | 现金流量表“经营活动产生的现金流量净额” | 单季同样用累计相减 |
| 期末可用现金 | 资产负债表“货币资金” | 扣除已知受限资金（保证金、质押）；不知道是否受限时注明 |
| 月均净消耗 | 近 3 个月（或本季）经营现金流 + 投资现金流中的维持性支出，取负值部分 ÷ 月数 | 产线建设等一次性资本开支单列，不混进日常消耗 |
| 现金跑道 | 期末可用现金 ÷ 月均净消耗 | 单位：月 |
| 应收 / 存货周转 | 期末余额 ÷ 单季收入 × 90 | 用于看回款和积压，有异常变动时才写 |

小企业会计准则报表（“会小企”）和企业会计准则报表的科目名称略有不同，按实际科目取数并在附注写明。

## 默认预警规则

用户仪表板或投资协议里有自己的规则时，以用户的为准。

| 信号 | 默认触发条件 |
| --- | --- |
| 现金紧张 | 现金跑道 < 9 个月，且下一轮融资未签约 |
| 现金危急 | 现金跑道 < 6 个月 |
| 收入落后 | 本年累计收入 < 年度目标 × 已过时间比例 × 70% |
| 毛利恶化 | 单季毛利率较上季下降超过 10 个百分点，或连续两季下降 |
| 回款变差 | 应收增速明显快于收入增速（超过 1.5 倍） |
| 存货积压 | 存货增速明显快于收入增速，且产线处于爬坡期以外 |
| 里程碑延迟 | 任一里程碑超过计划时间仍未完成，或管理层已表示将延后 |
| 亏损扩大 | 单季净亏损较上季扩大超过 30%，且收入没有同比例增长 |
| 关键人员变动 | 管理层汇报或公开信息显示核心团队离职 |

触发信号只说明“需要关注”，写清数字和规则，不等于风险已经发生。
