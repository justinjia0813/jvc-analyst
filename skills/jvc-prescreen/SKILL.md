# /jvc-prescreen — L0 项目初筛

## 3.0 适用级别

最低适用级别：**L0+**（Level 0 or above，零级及以上研究，用于从快筛开始按需增加流程）。

- L0 只生成 `01-prescreen.md`，不创建 `spec/` 或空的证据目录。
- 初筛出现值得继续验证的假设时，建议升级 L1，并在用户确认后使用项目模板建立 `spec/CONTEXT.md` 与 3–5 条 `spec/hypotheses.md`。
- 研究级别只裁剪工件，不裁剪来源标注、Bear Case、关键问题和不替用户决策的纪律。

## 目标与边界

默认执行 Research Level 0（L0，研究级别 0，指约 30–60 分钟完成、用于决定是否继续投入研究资源的快筛），只输出 `01-prescreen.md`。**L0 不初始化证据内核**（不创建 `evidence_registry.jsonl`、`audit.json` 或 `audit.md`，也不初始化 Research Core（研究证据内核）），不创建 Research Level 1（L1，研究级别 1，指开始建立结构化研究假设）工件，也不替用户作最终投资决定。

快筛只回答：商业链条是否说得通、赛道是否有真实需求和付费、市场可能处于什么区间、五年收入可能达到什么量级、给定交易条件时回报空间如何、下一步最该验证什么。它不是精确尽调、完整融资模型或最终投资建议。

## 反合理化约束

- “快筛不用精确模型，所以可以随便填数字” → 允许低精度估算，但必须公式、单位、来源、置信度齐全；没有任何市场锚点时只列公式，不输出市场数字。
- “按行业惯例大概是 X” → 无来源就写 `[未核实]` 或 `[需要用户提供]`，不得补估算值。
- “市场很大，不必测算” → 市场结论必须有口径、公式和区间；否则列为待验证假设。
- “缺少交易条款也能算回报” → 无估值或投资额时只给条件式敏感性框架，不给单点回报。
- “综合来看值得关注” → 这是终局判断；改为说明哪些假设值得继续验证及其缺口。

## 输入

- 项目材料或用户描述；
- 可选的融资金额、投前或投后估值、拟持股比例和交易工具；
- 可选的市场预测、经营数据和财务预测；
- 用户指定的地域、时间和投资口径；未指定时明确写出本次采用的口径，不能静默补值。

## 标签与缩写

所有实质性主张使用且只使用下列标签：

- `【第三方事实】`：独立于公司和用户的可定位来源；
- `【公司自述】`：公司、创始人、deck 或公司提供材料中的说法；
- `【用户观察】`：用户提供的判断、访谈观察或情景输入；
- `【模型估算】`：由可见公式和假设计算出的范围；
- `【未知/待验证】`：证据缺失、口径不清或单位无法勾稽。

首次出现的所有英文缩写必须给出英文全称、中文全称和一句简要解释。回报部分首次写：Multiple on Invested Capital（MOIC，投入资本倍数，指退出回款除以投入资本）与 Internal Rate of Return（IRR，内部收益率，指使投资现金流净现值为零的年化收益率）。Top-down（自上而下，指从有来源的上位市场逐层收窄到目标口径）首次出现时也要解释。

## 执行合同

### 1. 商业模式与产业链

- 在“商业模式”明确且恰好声明一个状态：`商业模式要素：完整` 或 `商业模式要素：缺失（客户/付费者/产品）`；
- 明确客户、实际付费者、产品或服务、收入方式和交付方式；
- 梳理上游关键供给、中游核心环节、下游最终客户；
- 判断价值由谁创造、由谁获取，谁有议价权，关键卡点在哪里；
- 缺少客户、付费者或产品任一项时，标记 `商业模式要素：缺失`，阻断五年收入与交易回报测算。

### 2. 赛道有效性

区分需求证据、付费证据、替代逻辑、产业阶段和反向信号。试用、送样、试点、签约、回款、续费和规模收入不可互相替代。前三项风险必须各自对应可观察的反证和下一步动作。

### 3. 市场规模粗算

在“市场规模粗算”明确且恰好声明 `市场锚点：存在` 或 `市场锚点：缺失`。锚点存在时，只使用 Top-down（自上而下，指从有来源的上位市场逐层收窄到目标口径）路径给低/中/高区间：

- 先写市场口径、公式和单位，再写结果；
- 每条 `【模型估算】` 同行写清 `公式：`、`单位：`、`依据：` 和 `置信度：`；
- 市场、收入和回报章节内所有定量模型输出行都必须带 `【模型估算】`、`结果：` 及上述四个审计字段，六个字段的值均不得为空，且 `结果：` 的值本身必须包含定量值，不能写“待计算”；
- 依据必须指明来源、用户输入或显式假设；无支持的行业常数不得进入基准情景；
- 没有市场锚点时，只列公式与证据缺口，写明 `市场锚点：缺失；处理：仅列公式，不输出市场数字`；
- 结果按决策有用的量级合理舍入，禁止无依据的小数精度。

### 4. 五年收入情景

只声明一条规范的“唯一驱动路径”，并按最贴近业务的驱动输出低/中/高三情景：

- 市场份额；
- 客户数 × 单客收入；
- 产能 × 售价；
- 或其他有披露依据的业务驱动。

其他路径必须写成 `其他单一驱动：具体驱动`。拒绝包含“与”“以及”“取平均”或“两条路径”的组合路径。不要强迫所有项目采用市场份额法。公式、单位、依据、置信度和关键敏感变量必须可见；市场规模和公司收入的口径要能勾稽。

### 5. 交易与回报粗算

在“交易与回报粗算”明确且恰好声明 `交易条款：完整` 或 `交易条款：缺少估值或投资额`。

在材料允许时列投资金额、进入估值、初始持股、稀释假设、退出收入、退出倍数、退出估值、回款以及 MOIC/IRR 区间，并让每一步可复算。

- 缺估值或投资额时，写明 `交易条款：缺少估值或投资额；处理：条件式敏感性框架`，只保留变量关系和待补输入，不给任何数值回报或结果（单点或区间）；
- 交易条款完整且回报章节未被单位问题阻断时，至少输出一条同时包含 MOIC、IRR、`结果：` 和完整审计字段的 `【模型估算】` 行；
- 数据足以做完整融资轮次、逐轮稀释和退出建模时，转交 `/jvc-roi-modeler` 即 Return on Investment Modeler（ROI Modeler，投资回报建模工具，用于逐轮稀释和退出情景测算），不在本 Markdown 复制完整模型；
- 交易回报只是条件式粗算，不构成投资结论。

### 6. 单位与传播

每个模型行先核对时间、货币、数量和分母口径。任一单位不能换算或勾稽时，同行标记 `【未知/待验证】单位勾稽：不兼容；下游传播：停止；影响章节：{章节}`。`影响章节` 只能是“市场规模粗算”“五年收入情景”“交易与回报粗算”的一项或用顿号连接的多项，或写 `影响章节：未用于模型`。只阻断声明受影响章节的定量模型输出；被阻断的市场章节不要求三情景，被阻断的收入章节不要求三情景或唯一路径，被阻断的回报章节不要求回报结果。局部缺口未用于模型时，不阻断其他口径独立且合法的模型。

## 固定输出结构

`01-prescreen.md` 的二级标题必须按以下顺序且只出现一次：

1. 快筛结论
2. 商业模式
3. 上下游与价值分配
4. 赛道有效性
5. 市场规模粗算
6. 五年收入情景
7. 交易与回报粗算
8. 风险、证伪条件与下一步
9. 来源、假设与未知项

产物必须声明 `Research Level 0（L0，研究级别 0，约 30–60 分钟的资源筛选）`。“快筛结论”必须写成唯一的 `研究资源判断：继续研究。`、`研究资源判断：等待关键材料。` 或 `研究资源判断：暂不继续。`，并写明不替用户作投资决定。“来源、假设与未知项”保留来源定位、用户输入、模型假设、置信度和证据缺口。

## 停止规则

- 无客户、付费者或产品：停止收入和回报测算；
- 无市场锚点：不输出市场数字；
- 缺估值或投资额：只给条件式敏感性框架，不给任何数值回报或结果（单点或区间）；
- 单位不兼容：标未知并停止下游传播；
- 无法把事实、公司说法、用户输入和估算分开：缩小结论，不猜测；
- 不输出“建议投资”“不建议投资”“应该投资”“推荐投资”“值得投资”或其他替用户决策的结论。

## 生成后检查

对实际产物运行：

```bash
python3 skills/jvc-prescreen/scripts/validate_output.py <研究目录>/01-prescreen.md
```

生产验证器只接受 basename 为 `01-prescreen.md` 的文件。验证失败时先修复产物，再交付；验证器只检查结构、标签、模型审计字段、停止标记和禁止行为，不判断投资结论。
