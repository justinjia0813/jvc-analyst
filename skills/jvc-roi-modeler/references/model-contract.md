# ROI Modeler 模型合同

## 来源母版

- `input_files`: 仓库根目录 `roi-modeler-template.xlsx`，用户提供的 `file-backed fixture`。
- 正式可复制结构：`templates/roi-modeler-template.csv`。
- `output contract`: 单个 CSV 文件，保持固定列、固定行项目和可审计公式。
- 年度标题可随项目平移；固定保留一个实际期、五个年度现金流期和三种同年退出情景。
- `rollback boundary`: 恢复上一版 `SKILL.md`、CSV 母版、校验器和 Research Core profile；不改写用户原始财务资料。

## 固定计算关系

1. 净利率 = 净利润 / 收入。
2. 公司估值按每列指定的唯一主估值方法计算；市销率只作交叉检查时，不得再次叠加进估值。
3. 无跟投时，轮后持股比例 = 轮前持股比例 × (1 - 本轮稀释率)。
4. 基金股权价值 = 公司股权估值 × 基金持股比例。
5. 退出总回款 = 基金股权价值；存在清算优先权、回购或其他分配条款时，以条款瀑布计算结果替代。
6. 净收益 = 退出总回款 - 累计投入资本。
7. MOIC（Multiple on Invested Capital，投入资本倍数，用于衡量总回款是投入资本的多少倍）= 退出总回款 / 累计投入资本。
8. 累计收益率 = 净收益 / 累计投入资本 = MOIC - 1；不得写成 MOIC × 100%。
9. IRR（Internal Rate of Return，内部收益率，用于按现金流时间衡量年化回报）的终期现金流必须使用退出总回款，不得使用净收益。年度等间隔现金流用 `IRR`；非等间隔日期现金流改用 `XIRR` 并增加日期行。

## 输入与证据

- 硬编码输入仅限：收入、净利润、融资估值、估值倍数、稀释率、投资金额和明确交易条款。
- 所有输入行填写 `[S编号]` 和假设状态；计算行不得伪装成来源事实。
- 缺失输入使用 `[需要用户提供]` 或 `[未核实]`，受影响的回报输出留空或返回 `NA()`。
- 金额统一使用一个币种和单位；若原始数据单位不同，先显式换算再进入模型。
- 本母版只覆盖基金不跟投。若基金在后续融资中追加投资，必须同步扩展持股计算、现金流和 validator；不得只增加现金流而沿用稀释后的持股公式。

## 完成检查

- 三种退出情景均从同一份财务预测和同一退出时点出发，只改变有证据支撑的估值倍数或退出假设。
- `proceeds`、`net_gain`、`MOIC`、`cumulative_return`、`IRR` 五行相互勾稽。
- 现金流至少包含一次负值和一次正值；否则不计算内部收益率。
- 输出通过 `skills/jvc-roi-modeler/scripts/validate_csv.py`。
