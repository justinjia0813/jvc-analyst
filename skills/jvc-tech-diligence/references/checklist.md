# 技术尽调检查清单

按项目所属领域挑用，不要求逐项填满。每项只记录会影响投资判断的发现。

## 通用

- **宣称的四要素**：参数、数值、测试条件、样品规模。缺一项就是待问问题。
- **谁测的**：公司自测、合作高校、第三方检测机构、客户来料检验（IQC，Incoming Quality Control，来料质量检验）。可信度依次升高。
- **重复性**：单次最好值还是多批次统计值；有没有标准差或分布。
- **理论上限**：宣称离理论极限多远；越接近越需要强证据。
- **对标口径**：对比对象是主流量产品还是论文冠军；比较对象是否被挑选过。
- **放大路径**：实验室 → 中试 → 量产每一步的产能、良率、单位成本、设备是否需要定制。
- **供应链**：关键原料和设备是否单一来源、是否受出口管制。
- **认证与导入周期**：客户验证要多久（车规、半导体产线导入常以年计），当前走到哪一步。
- **团队与工艺**：核心工艺 know-how 在谁手里，是否依赖一两个人；论文与专利的发明人是否在公司全职。

## 新材料

- 材料体系与制备路线（固相、液相、气相沉积等），与主流路线相比改了哪一步。
- 关键性能指标在什么条件下测得（温度、湿度、频率、循环次数）。
- 批次一致性：粒径分布、纯度、杂质、缺陷密度。
- 吨级或公斤级放大时的成本结构：原料、能耗、收率、设备折旧。
- 下游客户的认证流程与送样阶段。

## 半导体

- 工艺节点、器件结构、关键电学参数（迁移率、漏电、击穿电压、导通电阻等）和测试结构。
- 流片次数、晶圆尺寸、良率口径（晶圆级、芯片级、封装后）。
- 是否依赖特定代工厂或设备；替代方案。
- 可靠性测试（HTOL、TC、HAST 等）完成情况；车规或工规认证进度。
- EDA（Electronic Design Automation，电子设计自动化）工具和 IP 授权是否受限。

## 电池与储能

- 测试体系：扣式半电池、扣式全电池、软包、圆柱或方形电芯，容量多大。
- 能量密度口径：材料级、电芯级、系统级，质量还是体积。
- 首次库伦效率、循环寿命（截止容量保持率、倍率、温度、充放电深度）、倍率性能、低温性能、膨胀率。
- 安全测试（针刺、过充、热箱）完成情况。
- 与现有产线的兼容性：能否在现有设备上生产，改造成本多少。

## 能源与先进制造

- 效率或性能口径（实验室认证效率、组件效率、系统效率）。
- 寿命与衰减数据的来源和时长。
- 度电成本或单位产品成本的拆解与假设。
- 关键设备国产化程度和交期。

## 论文与专利怎么读

- 论文：看实验条件、对照组、样本数、补充材料里的原始数据；注意只报告最好结果的情况。
- 专利：看独立权利要求的范围、申请日与优先权、法律状态、权利人是公司还是高校或个人。
- 两者都只证明“有人做到过或想保护什么”，不证明公司产线做到了。
