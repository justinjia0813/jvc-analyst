# 全景报告合同

赛道研究“全景”模式使用本合同。交付 `tracks/{track-slug}/landscape.md`，读者是合伙人和投研同事。

## 写作原则

- **结论在前。** 第 0 节一页快照就要给出判断，后面各节是展开和依据。
- **判断占主体。** 每个重要判断按“证据 → 机制 → 对投资的含义 → 什么情况下会错”表达。不能改变任何下一步动作的信息只作背景，不进一页快照。
- **来源轻标注。** 关键数字、政策、公司事实后标 `[S编号]`，来源索引放文末附录。只有一个来源的关键数字照样用，标出“单一来源”；来源口径冲突时并列给出并解释差异，不取平均。
- **缺口转问题。** 找不到的写“暂无公开信息”并放进 H 节问题账本，不用低质量来源填满章节。

## 研究步骤

1. **定口径。** 赛道定义、排除边界、地域/时间/阶段假设、关键同义词和缩写消歧、本轮要支持的判断。英文缩写首次出现给英文全称、中文全称和一句解释。
2. **判断生命周期，分配研究权重。** 导入期重点看商业模式能否成立（谁付费、能否交付、单位经济）；成长期看规模（增长来自渗透、替代还是扩品类，供给跟不跟得上）；成熟期看防守和盈利（替代威胁、集中度、议价权）；衰退或再生期看替代速度和第二曲线。证据不足写“待判定”并保留两种解释。据此列 3–7 条可证伪假设，按“对下一步判断的重要性 × 当前证据缺口”排优先级。
3. **假设驱动检索。** 覆盖论文/专利/标准、政策/协会、公司官网/招股书/年报、行业报告、主流媒体/融资新闻、客户与采购侧材料。可信度大致为：论文/监管/公告 > 招股书/年报 > 行业报告 > 主流媒体 > 券商材料 > 公司 PR（Public Relations，公关稿）/融资新闻 > 自媒体。PR 只作线索。主动检索与初始判断相反的证据。
4. **因果链与周期。** 分开长期趋势和短期周期。检查需求/技术采纳、产能/库存、竞争/盈利、资本/融资四类周期，政策和技术冲击看它们如何改变这四类周期。每个适用周期给“上行早期 / 扩张中段 / 过热风险 / 下行消化 / 筑底早期 / 证据不足”之一，附领先指标、滞后指标、反向信号和信心。检查反身性：景气诱发过度扩产和宽松融资，低迷迫使出清并改善格局。
5. **停止。** 高优先级假设已被支持、被反证或明确无法补齐时停止；连续两轮检索不再改变生命周期判断、核心因果链或前三项优先级时停止。

## 报告结构

**0. 一页快照**（全文最重要的一页）
- 研究口径和默认假设（两三行）
- 当前生命周期阶段、依据、信心
- 可行性 / 规模性 / 防守性 / 盈利性四项初判
- 3–5 条关键判断，每条带证据、机制、含义
- 周期位置矩阵，和一条把关键周期串起来的核心因果链
- 3–5 条最重要的不确定性，以及什么信号出现说明判断错了
- 最值得投的环节可能在哪、为什么（写成待验证的判断，不写投/不投）

**A. 行业定义与边界**：是什么、不是什么、上下游边界。

**B. 行业简史与生命周期**：从技术或产业萌芽写起，每个阶段说清核心瓶颈、关键突破、资本/政策/需求变化，上一阶段解决了什么又暴露了什么。最后判断当前阶段和细分市场分化。

**C. 技术路线与商业可行性**：先讲原理和设计差异，再列代表公司。每条路线：原理、核心设计选择、关键部件、优势、约束、成熟度；比较时聚焦性能、成本、可靠性、制造难度、监管/安全、商业化时间的取舍；补充目标客户、付费理由、交付前提、单位经济是否已有证据。

**D. 产业链图谱**：上游 → 中游 → 下游的核心玩家和价值分配；谁掌握议价权、谁承担交付成本、谁最接近客户预算。关系比文字清楚时画图。

**E. 趋势、景气度与周期位置**：政策、技术、市场三类趋势，解释事件背后的驱动力；3–5 年展望，区分已发生事实和推断；四类周期的位置和反向信号。

**F. 关键玩家分层**：上市公司 / 成长期 / 早期，每家一句话定位。融资额不等于技术领先，媒体曝光不等于商业化。

**G. 监管 / 政策 / 标准**：现行的和讨论中的。

**H. 投资问题账本**：客户付费、技术壁垒、交付复制、单位经济、竞争格局、监管风险六类，每条写“假设 / 当前证据 / 什么情况下会错 / 下一步怎么查”。

**I. 后续交接**：
- 给 `jvc-workbook`：候选可比公司和比较维度；市场规模可建模变量、口径和缺的数据。
- 给 `jvc-interview-prep`：建议访谈的专家、客户、上下游角色和各自最该问的问题。
- 给 `jvc-thesis-test`：最强的 3 条正向假设和最危险的 3 条反向假设。
- 给研报渲染：研究写完后才交，渲染只排版不改内容。

**附录：来源索引**：`[S编号]` 对应标题、机构/作者、日期、链接、来源类型。

## 硬约束

- 不编造市场规模、玩家数据、政策条文；不写“万亿级市场”之类没有口径的话。
- 不用公司 PR 或融资报道代替技术路线解释。
- 不把单一指标或近期趋势线性外推；不混淆长期增长、生命周期和短期景气。
- 不输出“建议投资 / 不建议投资”。
- 中文输出。
