# Excel 计算验收

默认交付校验包含：数据行、来源编号、关键结果公式、实际重算、业务勾稽和输入变化测试。`--schema-only` 只用于刚生成的空模板，不能作为交付通过。

## 运行

本机需要 Python 的 `openpyxl` 和 LibreOffice。脚本寻找 `soffice` / `libreoffice`；非标准安装可设置 `JVC_SOFFICE` 为可执行文件路径。缺少重算引擎时明确报告“未完成计算验收”，不能降级成表头校验后声称完成。

市场规模或投资回报：

```bash
python3 "<仓库根>/scripts/validate-workbook.py" "<输出>.xlsx" "<仓库根>/templates/<模板>.md" --checks "<project>/_work/model.checks.json"
```

可比公司表不要求敏感性文件；仍检查数据、来源并重算已有公式。所有验证只读原工作簿，在临时目录重算副本。

## 独立预期

填写模型前先用输入和业务公式单独计算一个基准结果，再改变一个关键输入，计算预期结果。将预期保存在 `_work/model.checks.json`。预期不得从待验证的 Excel 结果格复制。

```json
{
  "schema_version": 1,
  "checks": [{
    "input": "assumptions!C2",
    "before": 1000000,
    "after": 1200000,
    "outputs": [{"cell": "top_down!G2", "before": 250000, "after": 300000}]
  }]
}
```

输入必须是数值假设格，输出必须保留公式。至少一个输出应发生变化。验证器分别重算基准和修改后的副本，核对预期；原文件不变。一页结论中的关键数字与验收结果再比对一次。

## 当前覆盖与边界

- 市场规模：自上而下乘法、自下而上量价渗透率、两路径差值及差值占自上而下结果的比例。
- 投资回报：本轮持股、逐轮融资及跟投、最终持股、累计投入、三情景、MOIC、按年度现金流核对 IRR。`investment_year` 与每轮 `year` 为实际口径年份，按年末发生；有跟投时不能用总投入的简单年化倍数代替 IRR。
- 旧版空表需要按当前模板补充首次投资年份 `investment_year` 和预测年初可用现金 `opening_cash`；公司现金不能用公司估值代替。
- 普通股回款核对为股权价值乘最终持股。优先股、可转债、分红、期权池变动、不同日期的现金流，需要单独补充条款模型和独立检查。当前验证通过不能证明这些特殊条款已经计算正确。只支持年度口径时，不把结果写成精确日期 XIRR。
- 公式通过本地引擎重算。外部工作簿引用、联网函数、迭代计算及未列入允许清单的函数会被拒绝。需要扩展时先补回归测试。
- 计算通过只证明给定输入下的计算关系；不能证明输入或估值假设真实。

工作簿各表至少有一行实际内容。没有覆盖缺口时在 `coverage_notes` 写“本次范围内未发现”；不适用的解释项写清原因。缺关键计算输入时交付不完整草稿和缺口，不能用 0 凑出通过结果。
