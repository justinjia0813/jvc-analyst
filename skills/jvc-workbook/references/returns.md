# 投资回报模式

按本轮条款、后续融资和退出假设，逐轮计算稀释，得出三种情景下的回款、MOIC（Multiple on Invested Capital，投资倍数）和 IRR（Internal Rate of Return，内部收益率）。只要一个快速判断时，可以不建完整八张表，只交一页结论加一张稀释-退出简表（见文末“快速模式”）。

## 输入

| 类别 | 内容 |
| --- | --- |
| 本轮条款 | 投资金额、投前/投后估值、持股比例、优先权、期权池 |
| 财务预测 | 未来 3–5 年收入、毛利、EBITDA（息税折旧摊销前利润）、净利润、现金消耗 |
| 后续融资 | 预计轮次、每轮金额和估值、是否跟投 |
| 退出 | 保守/中性/乐观三情景的退出估值或倍数、退出年份 |

缺的输入先问用户；用户说不知道时，给有依据的估算（例如可比公司的融资节奏、同阶段常见稀释比例），在 `sources` 表标“估算”和依据，并在结论里写明结果对它有多敏感。

## 步骤

1. **逐轮稀释。** 从本轮开始逐轮算新增股份、持股比例、累计稀释；跟投时加上追加投资和持股。不用最终持股倒推。
2. **三情景退出。** 退出估值、持股价值、考虑优先权后的回款、MOIC、IRR（按退出年份）。
3. **敏感性。** 对退出估值、稀释轮次、跟投比例等核心变量做 ±20% 矩阵。
4. **临界条件。** 算出回本（MOIC = 1）和达到用户回报门槛所需的退出估值；用户没给门槛就只算回本，不代设门槛。

## 工作表

`investment_terms`、`financial_forecast`、`financing_dilution`、`ownership`、`exit_scenarios`、`returns`、`sensitivity`、`sources`。

## 规则

- 基准情景要有依据；乐观和保守并列展示，不拿乐观当基准。
- 退出倍数参照可比公司时，写明业务模式、增长阶段、流动性差异和折价理由。
- 一页结论写：三情景的 MOIC/IRR、回本需要的退出估值、最敏感的两个变量、稀释最重的一轮。

## 快速模式

只要判断“按这个价格投，大概要什么退出才划算”时：跳过完整工作簿，交一页结论加一张表（轮次、融资额、估值、持股、退出估值、回款、MOIC），计算仍实际执行并保留脚本。
